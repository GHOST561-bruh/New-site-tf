# Database Folder

This folder contains database-related files:

- `schema.ts` - Database schema definitions
- `migrations/` - Database migrations (create as needed)
- `queries/` - Pre-built database queries (create as needed)

## Setup

1. Choose your database (PostgreSQL, MongoDB, etc.)
2. Add connection strings to `.env`
3. Define your schema in `schema.ts`
4. Create migration files as needed
